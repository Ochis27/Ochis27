## About me

- ☁️ I deploy and operate containerized applications on **AWS (ECS Fargate, RDS, S3, ECR, IAM)**, with infrastructure written in **AWS CDK**.
- 🔁 I build **GitHub Actions** pipelines for linting, testing, security scanning and deployment.
- 📈 I set up monitoring with **Prometheus and Grafana** and single sign-on with **Azure AD**.
- 💻 I work across the stack with **Next.js, React, TypeScript, FastAPI, Java/Spring Boot and PostgreSQL**.
- 🤖 I also build applied AI systems (RAG, LLMs, computer vision) and co-authored a paper accepted at **SYNASC 2026**.
- 🎯 Currently learning **Terraform, Kubernetes and cloud security**, with Terraform Associate and CKA on my roadmap.
- 📍 Based in **Timișoara, Romania**.
